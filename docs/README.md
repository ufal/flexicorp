# Flexicorp documentation

Technical docs live in the flexicorp repository so TEITOK projects do not need to ship them.

- **[install-manatee-bindings.md](install-manatee-bindings.md)** – How to install the Manatee Python bindings for the Manatee backend.

To make the “How?” link in the flexicorp UI point to these docs without copying this folder into each project, set **flexicorp/docs_url** in TEITOK to the base URL of the published docs (e.g. your flexicorp repo’s `docs/` on GitHub or your own server). Example: `https://raw.githubusercontent.com/your-org/flexicorp/main/docs` or `https://yoursite.org/flexicorp-docs`.
